# Code of Conduct

Be decent. Discuss wording in good faith. Disagreement about license design is welcome; personal attacks are not.

Unacceptable behavior gets a warning; repeated or egregious behavior gets blocked from the repository. Maintainer discretion applies.

This is a license repository — the "conduct" that matters most is honest citation: do not claim this license is certified under any standard it has not been certified under, and do not relicense fenced copies as CFSF.
