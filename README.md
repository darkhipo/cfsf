# The Copy-Free/Stays-Free (CFSF) License

**What this is.** The canonical home of the CFSF license wording — a two-clause-feel, one-provision permissive license. Version 1.0 (2026-11-09). The license text lives in [LICENSE](./LICENSE); this repository is the citable definition.

**Why it is up.** Every CFSF-licensed work should point at one stable, public definition of what its terms mean. The wording is small, deliberate, and meant to be read by humans, not just lawyers — this repo keeps that wording findable, quotable, and unchanged.

**What the name means.**
- **Copy-free** — use it for any purpose, commercial or not: copy, modify, distribute, sell.
- **Stays-free** *(with the s)* — nobody gets to fence it. The one provision: you may not license, restrict, or claim ownership of the work or any copy of it. Your additions may be licensed however you like; the work, as given, remains free.

**Name-collision record.** Checked 2026-11-09: `CFSF` is unclaimed in software licensing (the acronym's only other user is a foster-care services foundation); "stay-free license" returns no prior art. Deliberately **not** "Copyfree" — that word is the Copyfree Initiative's certification mark, and this license is not certified under their standard (the anti-enclosure provision is a condition their definition excludes). The distinct name earns the distinction.

**How to apply it.** Drop the [LICENSE](./LICENSE) text into a file named `LICENSE` at your project root. Done. If your project vendors third-party code, keep that code under its own upstream terms and note the boundary (a `NOTICE` file naming each vendored portion and its license) — CFSF covers your work only.

**What work can be done here.** Translations and wording clarifications that do not change meaning. The text itself is **frozen for existing adopters**: any future revision will be a new version number, never a silent edit of 1.0. Open an issue to discuss anything.
