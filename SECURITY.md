# Security

This repository contains no runtime, no services, and no dependencies — it is license text and documentation. There is nothing here to exploit.

If you believe you have found a defect in the license *wording* (an ambiguity that could be exploited against adopters), please open a private security advisory or an issue. Wording defects are treated with the seriousness of security defects — that is the whole point of a canonical home.
